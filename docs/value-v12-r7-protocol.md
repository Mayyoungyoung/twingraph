# R7：修复物理和候选覆盖后重新收集

本文件预先声明下一批实验。当前状态为开发验证，尚无 R7 正式训练或盲测结果。R6 的全夹爪碰撞未启用、销验收仅覆盖端挡，因此 R6 标签和权重不能用于本批结果。旧 online 比较已按用户要求停止，部分记录保留，不计入完整比较。

## 开发门槛

1. 保留原打印 STL、孔和夹爪尺寸。完整手掌、手指、指垫均参与物理碰撞。修复 MuJoCo 2.3.7 共面矩形接触退化时，只允许等几何后端表示或通用合法初始化，不允许按布局改孔径或删除碰撞。
2. 固定检查 1800–1809 的初始分布，不重采失败布局；基座与所有待装配物体由腕部 RGB-D 观测。初始物理异常、感知未知、候选生成失败分别记录。
3. 每个开发布局先生成共同候选池，最多 48 个完整计划。必须实际观察到从未装配状态开始，经清洁、全部装配、行程测试、两销保持和回位的成功，才能宣布该布局有覆盖。单独插销成功或静态避碰不能替代。
4. 若开发池缺少成功，检查具体前序效果、抓持、规划和执行原因后修改实现，再用新快照重新检查；保留旧失败。禁止用最后一次仿真结果作为新候选的“预知”特征。开发种子永久排除于正式数据。

有限候选集不能数学保证所有未见物理场景都有成功计划。此处保证的是正式收集前有完整的开发覆盖证据，并在盲测中单独报告候选池覆盖率；不得删除全失败场景或用成功答案补充盲测池。

## 候选及统一接口

符号顺序和技能种类由当前任务指定；抓取方向、安装方向、抓高来自观测物体和接收部件 CAD。销具有独立的供料抓取方向和接收孔插入方向，先拔出供料筒再转向。检查完整夹爪的采样插入、开爪、退回空间；已知碰撞拒绝，未知留给孪生。

端挡放置后重新观测，检查两个端挡孔与底座孔的共同直轴通路。没有通路则该前序阶段未完成，不能继续插销。插销命令深度、额外压入预算、孔口和方向是显式执行端口；验收要求同一根销占据端挡与底座两层并松爪保持。没有理想世界位姿误差门限。独立物理验收可读取仿真真值，感知、目标生成和控制指令不得读取物体真值。

采样几何条件通过 `geometry_conditions` 进入技能图，并绑定完整 PlanIR、选择参数、顺序、观测和 CAD 摘要。价值模块与廉价几何排序对照读取同一记录。几何通过只是必要条件，不是接触执行成功标签。

执行期重新观测后、编译阶段程序前，根据同一个视觉接收关系规则绑定目标；每阶段保存实际 PlanIR 和观测摘要。不能悄悄修改已经评分的执行调用，不能把前序预测安装位置当成已经观测到的状态。

## 数据与模型（尚未开始）

1800–1831 仅开发；所有旧 1600–1714 数据退役。供料物体随机位置与朝向；滑块、端挡和手柄共用位置区域，销与供料筒成组移动。构造仅按 CAD 不重叠约束，不按成功标签或检测结果重采。各预算的候选内容嵌套。

冻结完整 Python、XML、STL/OBJ/MSH、学习技能权重、配置与采集脚本摘要后才收集。完整矩阵保留所有物理失败；超时、源码变化、进程异常属于无效/资源截断，不能当负标签。并行采集耗时不作为在线方法时延。

固定比较 linear、共享阶段编码模型、类型关系图模型；后两者共享局部可行性头与全计划表示。损失包含全计划真实基率 BCE、同布局正负排序、执行阶段掩码辅助任务；未执行阶段不伪标负例。训练集归一化、布局等权。训练种子 1212，120 epochs，宽度 48。

只按验证集依次最大化 Hit@4、最小化归一化找到首个成功所需验证次数、最小化 Brier；同分选最早 epoch 和固定模型顺序。验证池全无成功时禁止选出“有效排序模型”。旧 schema 权重明确拒绝加载。

## 冻结模型后的比较

各方法共享相同观测、候选池、完整任务验收与资源预算：全部孪生；随机 top-4；价值 top-4；随机顺序找到首个成功；价值顺序按 4 个一批扩展直到首个成功；廉价几何余量排序。几何对照用于区分显然碰撞剔除与学习到的接触/前序失败预测。

分别报告池覆盖率、条件于池内有成功的 Hit@4、整体任务成功率、Brier、孪生调用数，以及候选生成/排序/验证/部署/重规划实际时间。不能把 `top-k` 的少算当作准确性保持；需用相同布局配对比较并披露不确定性。八个盲测布局是系统先导实验，不足以单独支撑最终 RAL 性能结论。
