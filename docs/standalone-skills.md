# 独立底层组件演示

现有 30 段视频用于解释底层控制、计算和检查能力，不表示 30 个平级任务技能。任务级划分见 [架构设计](architecture.md)。

| 独立场景 | 展示能力 |
|---|---|
| 三个彩色方块 | 检测、位姿、抓取候选及选择 |
| 单个 40 mm 方块 | 接近、闭爪、验证、抬升、下移、释放、回位、转腕与直线运动 |
| 固定灰色障碍物 | 避障路径规划及计划/实际轨迹对比 |
| 单根插销与真实通孔孔座 | 对齐、接触停止、压靠、恢复、寻孔、学习插入与验收 |
| 短导轨与滑块 | 约束插入、推拉、行程和间隙检查 |

每段使用固定 MuJoCo 镜头，插销采用更近的固定视角；底部显示组件名称及标记解释。没有网页前端或切镜头。

## 标记含义

- 检测透明球来自实际观测数组的中心估计；当前后端是仿真位姿传感器。
- RGB 坐标轴来自位姿旋转矩阵；抓取框的位置、方向与开度来自实际候选。
- 青色关节路径由规划关节序列在独立数据中做正运动学得到；黄色轨迹来自实时执行。
- 接近/上下移等方向箭头带引线，放在夹爪侧面提高可见性，实际轨迹不平移。
- 绿色接触点来自真实指垫接触，橙色点来自外部接触；力值通过 MuJoCo 接触力接口计算。
- 绿色孔轴固定在真实孔口。保护下降故意偏离孔口，展示接触停止，不能当作插入成功。
- 间隙取自几何边缘；行程检验显示前序真实运动记录。检测、规划和验收本身不额外驱动机械臂。

标记只加入渲染场景，不加入物理模型。每段记录检查渲染前后物理状态一致，以及标记确实产生可见像素变化。成品检查首、中、末帧与文件哈希。

## 代码与复现

`demo_scenes.py` 构建专用场景；`demo_visuals.py` 绘制空间标记；`standalone_demos.py` 执行和录制；`deliver_demos.py` 汇总成品。

同一 Session 组件通过场景对象清单与抓取尺寸复用。录制前用真实控制器达到准备状态，独立演示从该状态执行；没有把方块伪装为装配零件。

查看 [全部视频索引](demos/INDEX.md) 与 [小方块抓取组合示例](demos/cube_grasp.mp4)。重录命令见 [运行指南](setup.md)。插销沿用行为克隆权重；单次演示通过不是新的鲁棒性统计。
