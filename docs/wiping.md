# 擦拭：学习轨迹与实际接触

当前 `wipe` 是新的接触执行原语，`plan_path(method="surface")` 是原路径规划节点的一种参数分支。机械臂抓持被动擦拭工具，在导轨底座中间的平面上往复擦拭；没有工具执行器、物体焊接或物体位姿强制写入。

## 学习内容

程序化专家生成三次横向往复、两次侧向换行的归一化轨迹。24 条轨迹加入平滑小扰动，以岭回归拟合 101 个归一化高斯径向基的 XY 权重。推理输入阶段进度和目标区域，输出连续参考位置。高度由表面参数和实际接触反馈决定。

训练集：`checkpoints/wipe_expert_demos.npz`；权重：`checkpoints/wipe_imitation.npz`；报告：`checkpoints/wipe_imitation.json`。训练随机种子 173。验证使用 800 个未参与拟合的相位点，归一化 RMSE 约 0.00221；这只是轨迹拟合检验，不是新任务泛化成绩。

```bash
python -m simbench.assembly.wiping
```

## 执行与成功判定

执行器调用已有 `PoseController.servo`，持续确认真实双侧抓持，读取工具与目标表面的接触力，限制高度命令变化率。软接触参数仅应用到新擦拭垫。达到力限、失去抓持或跟踪失败均不能判成功。

覆盖率统计在固定目标区域的 40 × 12 网格上：仅当真实表面接触力超过 0.15 N，才计入工具实际位置与几何足迹覆盖的格点。绿色小点代表已覆盖采样位置，不是模拟材料真的被去除。

成功要求覆盖率至少 90%、有接触的控制步占比至少 55%、XY RMSE 小于 3 mm，且不超过指定力限。当前演示覆盖率约 95%，接触步占比约 85.9%，峰值力约 3.28 N。逐次实际数值以 [验证文件](evidence/surface-assembly/README.md) 为准。

这是轨迹模仿学习与解析接触反馈的组合，不是强化学习，也没有学习整个机器人动力学控制器。当前只验证平面矩形区域；曲面抛光、磨料去除及粗糙度改善需要新的模型、数据和试验。
