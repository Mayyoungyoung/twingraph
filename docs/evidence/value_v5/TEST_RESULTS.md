# 锁定测试结果

模型及分类阈值已在提交 `baaafd1cdbe9360a363c8836fbb95fff9f32c3d8` 中发布，随后才采集测试配置 61300–61311。
主模型固定为 `mlp_29`、N=12、K=4。测试共 12 个配置、144 条候选，65 条成功；没有配置缺失、超时或全失败候选池。

| 指标 | 锁定测试结果 |
|---|---:|
| 候选准确率 | 103/144 = 71.53% |
| 平衡准确率 | 70.10% |
| ROC-AUC | 0.7729 |
| Brier 分数 | 0.1933 |
| TP / FP / TN / FN | 36 / 12 / 67 / 29 |
| Top4 至少一条成功 | 11/12 = 91.67% |
| Top4 中成功候选比例 | 32/48 = 66.67% |
| 原始顺序 Top4 命中率 / 成功候选比例 | 11/12 / 22/48 |
| 均匀无放回随机 Top4 的精确期望命中率 / 成功候选比例 | 84.23% / 45.14% |

准确率的配置级 bootstrap 95% 区间为 60.42%–80.56%，Top4 命中率为 75%–100%。
相对随机筛选的命中率差区间为 −9.07 至 +23.91 个百分点，不能宣称显著提高命中率。
相对随机筛选的成功候选比例提高 21.53 个百分点，区间为 +11.11 至 +30.56 个百分点。
原始顺序 Top4 也命中 11 个配置；当前结果主要支持成功候选富集，不支持优于原始顺序的命中率结论。

所有模型、阈值、预测和配置级区间见 [完整指标](test_metrics/metrics.json)及[逐候选预测](test_predictions.json)。
四个模型的测试结果全部保留，不因测试表现更换部署模型。
这些是 R1 名义仿真结果，独立目标执行与实际耗时另见最终系统报告。
