# 测试前模型冻结

此目录的 `model_selection.json`、`thresholds.json`、验证预测，以及
`models/value/v5/` 的四个模型，在测试配置 61300–61311 采集前提交。
正式系统配置为 61400–61403，主方法固定为 `mlp_29`、Top-4 / 12。

模型按验证集 Brier 分数选择；分类阈值为 0.5695365870155553，
只影响二分类统计，不改变按模型输出排序的 Top-K 策略。
标签是完整五部件程序的实际仿真执行成败，没有人工加权奖励。

验证数据为 12 个独立配置、144 个候选，训练数据为 48 个配置、576 个候选。
模型输入的 7705 列由状态和程序接口自动生成；仅用训练集剔除常量及完全重复列后为 80 列。
这些数字不是跨任务固定的人工特征清单，也不能说明该表示已最优。

本目录保留模型选择时的原始路径；复现时可按运行指南提供同 SHA-256 的迁移路径。
测试与系统结果发布后另列，不把本次验证指标当作测试指标。
