# V10 针对性候选：独立测试预注册

代码冻结点以本文件提交为准。旧任务仍为 `functional_assembly_v9_funnel_r1`；
几何、功能验收、RGB-D 接口不变。新方案来源标记为
`script_targeted_grasp_v10_r1`，不是在线大模型规划。

使用 L1 生成器，预先指定三个未用于开发、交叉验证或方法选择的 seed：
1320、1321、1322。每个 seed 仅跑名义物理条件。旧 V9 12 候选和
新 V10 12 候选分别完整执行；每个候选使用新 Session，失败与异常保留。
新池具体名称和参数由 `scripts/collect_v10_paired_test.py` 的 `NEW_NAMES`
以及 `simbench/value/v10_candidates.py` 固定。旧池原封不动。两池比较
可解覆盖时采用同一布局、同一任务版本、同一完整成功验收和 K=2/4/12。

随机顺序使用精确组合期望。参考优先、规则、旧数据训练的全局线性、
交互 MLP、V6 BCE 和 V6 BCE+同场景排序损失均在同一新候选池回放；
训练只用 seed 1302–1313 的旧池数据。`approach_strategy` 在旧训练数据
中从未变化，因此学习模型对这个新维度没有训练依据，迁移结果须单独标明。
新测试结果不用于重排新候选池、调参、选择排序方法或训练模型。

这组小样本是针对性独立测试，不是新的 12×12×3 大矩阵；不据此宣称
统计显著或真实机器人效果。
