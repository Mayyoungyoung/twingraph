# V24 采集安排：V23 任务与验收保持不变

本轮仅改变开发采集的场景和候选预算。任务仍是无擦拭的完整滑台装配，插销须同时进入挡板孔与底座孔，并在功能行程后保持接合；原子技能、MuJoCo 位姿观测后端和零噪声主条件均沿用 V23。固定安排见 [collection_manifest.json](collection_manifest.json)。

八个新布局中，2062–2065 来自原定工作范围，3005–3008 来自预先定义的 2050 供料邻域。每布局生成 48 个提案，在读取任何结果前冻结并执行前 8 条不同的完整程序。它们的首批自然覆盖率将以全部八布局、64 条候选为分母，包含所有全负池。

3000、3002 是 V23 原定首批已有的混合池。本轮各追加原 48 提案固定顺序中的第 9–16 条，共 16 次。追加前重新生成提案并核对原先 8 条的程序哈希和决策观测，防止把一套新候选冒充旧池的后续顺位。选这两个布局使用了既有开发结果，所以追加数据单列，不回填其首批覆盖率，也不称为独立测试。

零件供料布局只按 CAD 足迹、预设供料区与最小间距等条件产生；没有按执行标签筛选坐标。若某布局 8 条均失败，保留原因并继续下一布局。少量新增正例将按预先声明的条件单独复验，重复标签不回填首批。

完成后报告三项判断：新布局是否出现原邻域以外的正例；追加候选是否形成不同的成功抓取／路径选择；以及各布局来源的正负覆盖是否足以支持按来源分组的训练与验证。执行中产生的逐条样本、异常和原始轨迹均保留。

## 本轮三个问题

**1. 正例是否走出原来三个邻域布局？是。** 新的原范围布局 2062、2063、2064 各有一条完整正例。3006、3008 邻域也有正例；2065、3005、3007 的全负结果完整保留。新布局不是以执行标签筛选出来的“保成功”坐标。

**2. 是否出现不同的成功做法？是，有一组同布局直接证据。** 3002 原成功候选 `grounded_033` 与追加成功候选 `grounded_011` 使用相反的左右销顺序；滑块、挡板和两根销的实际抓取角度均不同，10 次搬运规划的选中路径 ID 也全部不同。两条均通过释放后及行程后的双层孔验收。详情及原始路径 ID 见 [analysis.json](analysis.json)。这些记录证明执行时的抓取与路径选择不同；目前没有对完整连续关节轨迹做距离统计，因此不把 ID 差异表述为轨迹距离结论。

**3. 能否按布局来源分组训练／验证？可以做开发性小样本分组试验，尚不能可靠宣称泛化。** 新首批有 5 个划分组：2062、2063、2064 三个独立原范围组各有 1 正／7 负，2065 组为 0 正／8 负，2050 母布局的四个新邻域布局必须合为一个组，共 3 正／29 负。可把整个母布局组放在同一数据划分，并留出一个原范围正例组做探索性验证；每个独立原范围组只有一条正例，指标方差会很大。V23 的 2050 母布局及其旧邻域样本也必须并入同一组，不能拆到训练和测试两侧。

## 单列复验

从新增正例中选定三条，各在相同初态／随机状态及改变预先声明的物理扰动后重放一次，选择理由见 [replay_selection.json](replay_selection.json)。2062 的 `grounded_021` 与 3006 的 `grounded_002` 同条件再次成功，换扰动后均为控制／接触失败；3002 追加的 `grounded_011` 两次都成功。逐条复验记录分别见 [2062](replay_broad_2062_samples.jsonl)、[3006](replay_near_3006_samples.jsonl)、[3002 追加](replay_append_3002_samples.jsonl)。这 6 条不进入基础采集分母，也不是精确成功概率；其他单次正例尚未复验，不能视为已证实稳定。
