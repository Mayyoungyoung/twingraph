# V22 无擦拭滑台完整装配：状态观测与候选覆盖

**任务边界更新：**本页 V22 只要求插销进入挡板孔，未把进入底座孔作为成功条件。用户随后要求底座孔插入为必需条件；因此下列 17 条执行与逐条结果继续保留作历史开发证据，但其 V22 正标签不能用作新任务的正标签，也不能直接改写为新任务标签。新任务使用独立的 V23 版本和重新执行的验收。

任务版本 `sliding_assembly_no_wipe_v22` 从滑块开始，依次放置挡板、两枚插销和把手，再执行双向滑台行程、释放与机械臂撤回。擦拭既不在候选程序中，也不在阶段成功条件中。布局仍使用印制件 MuJoCo 场景；本实验不是实物验证。

决策时观测来自 MuJoCo 位姿，可按位置与偏航独立加零均值高斯噪声。候选先由既有几何提议器生成，去掉擦拭参数后按候选顺序冻结并去重；各候选随后从同一布局的全新初态单独执行。标签不参与冻结或选择。运行时源码/CAD/策略指纹为 `9bdfa42975a85039507cd637347ffc13d20d9451a15c702679067f8fe79fceba`，执行域为 `online`，其物理扰动随布局种子固定。

| 布局 | 状态观测噪声（位置/偏航标准差） | 冻结候选 | 成功 | 失败 | 主要失败阶段 |
| --- | --- | ---: | ---: | ---: | --- |
| L0, 2050 | 0 / 0 | 3 | 3 | 0 | — |

总计 **17 个有效完整执行样本：4 正、13 负**。0.3 mm/0.3° 的四候选池在**同一个决策观测**下得到 **1 正、3 负**，可用于候选筛选的初步训练与审计。0 噪声的 2050 池 3/3 成功，2051 池 0/4 成功；布局变化本身显著改变可行性。1 mm/1° 的 2050 池 0/4，均在滑块入轨时过载。因此不能从本小样本推断一般化成功率或噪声阈值。

V22 的局部验收按功能定义：挡板在安装区域内释放后由基座稳定支撑，插销在挡板孔内保持插入；双层孔贯通、理想位姿残差和定位柱捕获保留为诊断，不强加为本任务标签条件。滑块需保持在导轨包络内，把手需与立柱形成环孔接合，双向行程及最终撤回仍需通过。0.70 mm 的把手径向偏移超过约 0.60 mm 的实际环孔间隙，故保留为失败。运动到位的 V22 局部容差为 1.5 mm；真实抓取接触与后续功能验收没有跳过。

[`samples.jsonl`](samples.jsonl) 的每行均包含：决策时观测、完整控制器候选 PlanIR、五零件原子装配 PlanIR、实际执行标签、首次失败原子及实现、阶段到达/完成、最终功能谓词、观测后端及噪声随机状态、运行时指纹、物理扰动、耗时、超时与软件异常。观测噪声随机状态单独存储，未混入模型可见的 `decision_observation`。原始逐原子轨迹与逐阶段重绑定程序位于各 `results/v22_*` 运行目录；可移植 JSONL 自身已有完整候选与标签。每个候选的原子计划在决策时给出，阶段执行时按新观测重新绑定接收目标，控制器入口与运行时指纹保证此过程可复核。

[`audit_report.json`](audit_report.json) 记录六组冻结请求与执行样本的完整性检查，包括 PlanIR 哈希、观测一致性、运行时指纹、无擦拭范围、标签与功能谓词。六组均完整通过；没有超时或软件异常样本进入上述 17 个有效标签。
