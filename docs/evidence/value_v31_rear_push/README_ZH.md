# V31：释放滑块后，用闭合空夹爪从后方推入导轨

## 动作与任务边界

滑块先在导轨入口受支承放置并释放。夹爪升到滑块上方，移至滑块后方，**空夹爪闭合**后下降到后端接触高度，再沿导轨正向推进。控制器检查夹爪开度、末端是否始终在滑块后方、接触力及滑块真实位移；没有重新抓取滑块。推送前若滑块自行滑到目标附近但没有建立后方接触，仍判为失败。

把手安装前重新观测滑块位姿并规划；本轮使用 MuJoCo 状态位姿。安装并验收把手后即结束，不执行把手往返滑动。

## 随机布局结果

同一随机 L0 broad 布局 seed=2788，regression 域，位置及偏航观测噪声为 0。16 条完整候选在执行前冻结，**有效 16/16，完整装配正样本 0/16**。失败技能：后方推送 13，滑块接近抓取 3。

13 条推送失败中，8 条发生后方接触并推进约 13～27 mm，但持续高接触力使控制器停止；另 5 条在计划推送接触形成前滑到目标附近，接触样本为零，因此不能算作后方推送成功。四个窗口的初始观测与 16 个计划哈希一致；运行时 SHA-256：`e1f45ca16c223cc212c6b8a3030772364e9e45371850966276d34e4fda4d8600`。此前 V30 的 0/16 使用了释放后重新夹持的错误动作，与本轮标签不同。
