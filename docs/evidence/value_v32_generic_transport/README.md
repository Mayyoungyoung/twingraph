## 任务与方案

任务从滑块开始，到把手安装、释放和退回后结束；不要求初始擦拭和最终滑动测试。原有独立验收保留：装配、夹具捕获、最终座合、释放退回、两根销贯穿底座，必须全部通过才能记完整正例。

大模型读取布局初始观测、声明 CAD、统一原子图谱与候选参数库，在物理执行前组合并冻结 8 条候选。保持夹持送入和放下后推动均合法，没有指定每个布局必须选择某种方案或强制策略配额。参数库是已有任务规划先验，模型可选择各零件的参数与次序；当前还不是任意自由生成的新控制器。模型请求、响应、哈希与每条 PlanIR 均归档。

## 原子库与执行器

- 同一注册表导出 13 个公开原子节点、26 条条件依赖边，静态契约和真实执行共用。见 [图谱](../../skill-graph/README.md)。
- 推动拆为位姿估计、接触位置估计、路径规划、移动、空夹爪闭合和接触推动。推动控制器没有零件名或任务成功分支，仅用观测、CAD 和真实夹爪接触反馈；支持水平、具有声明外露盒形接触面的物体。
- 接触推动限制命令超前量，遇过载卸力，检查闭合夹爪始终位于物体后方；要求实际进度与接触期间进度，漂移不能作为成功。
- 通用放置按当前开度加小余量释放；下一次抓取在悬停位重新打开夹爪。
- 修复平面凸网格单接触的数值漂移：启用 MuJoCo 多接触。独立无机器人实验中，同一 2 ms 步长下横向漂移从约 5 mm 降到微米量级。没有改变 CAD、摩擦或验收阈值。
- 使用稀疏雅可比加速接触求解；IK 仅计算运动学与质心坐标，碰撞检查仍执行完整前向过程。五组状态的末端位姿和雅可比与原完整前向逐元素一致。

## 采集门槛与数据

正式验证布局预先指定为 3200、3201、3202，每布局 8 条。要求至少 3 个完整布局、有效率至少 95%、正例比例至少 12.5%、至少 2 个同时含正负例的布局，以及足够负例。单条正例不足以判定通过。

通过门槛后自动启动固定布局 3300—3424，共 125 × 8 = 1000 条。布局预先分组为训练、验证、测试，候选不按结果补抽；资源超时为无效标签，不能当成负例。运行时版本变化、无效样本或至少 3 个布局组成的整批全负会暂停扩大采样。验证并行 3 个布局；正式采集并行 8 个布局，批边界最多 64 条。正式采集同时保存脚本源码副本；验证调度脚本的原始副本保存在上传的 `v32_runtime.tar.gz` 中，之后仅扩展了调度并行度和源码归档，冻结物理源码未变。
