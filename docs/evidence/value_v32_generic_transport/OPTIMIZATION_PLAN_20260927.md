# V32 价值模块改进分析

本文件是下一轮实验建议，不改变已冻结V32结果，不启动采集或重训。依据已完成的1000条审计数据、39次流程实测、输入张量和训练代码。诊断数据见 `OPTIMIZATION_DIAGNOSTICS_20260927.json`。

## 1. 已确认的现象

| 现象 | 证据 | 含义 |
|---|---|---|
| 排序已有效，但整体目标未达成 | 离线Hit@1：价值69.2%，随机精确期望38.5%；Hit@4：92.3% vs78.9% | 已学到名义成功的排序信息 |
| 孪生通过不代表换扰动后通过 | 实测三方案均在12/13布局找到通过者，最终价值9/13、随机/Full8各10/13 | 应直接监督同一计划跨扰动的可靠性 |
| 数量收益被单次运行成本稀释 | 价值20次验证，随机26次；失败验证耗时合计1290秒 vs2482秒 | 失败验证成本已明显下降，整体还包含必需的成功验证和最终执行 |
| 继续只改善排序的空间有限 | 固定Top4、首个通过即停，12个可解池和1个全负池；事后理想排序需12×1+1×4=16次 | 20次距离16次仅差4次；该事后下界不能直接作为在线策略 |
| 预留物理信息没有实际输入 | 1000样本/111077节点中，6个geometry字段和7个robot字段均为0 | 几何状态/裕量未传入；机器人若初态固定，缺失未必是主要瓶颈 |
| 验证指标过早饱和 | 三个初始化validation Hit@4均100%，前两个调用均1.083 | 12布局验证集对选择的区分能力弱；不能由此认定过拟合已经得到证明 |

当前价值流程平均728.03秒，其中成功候选的验证合计4545.08秒/13=349.62秒，再加最终执行均值277.96秒，约占整体86.2%。全部8候选的编码与推理仅0.923秒。继续优化网络推理延迟不会解决当前耗时问题。

输入仍有对象位姿、动作参数和图关系，因此不能说模型完全没有几何信息。303个通道中160个在当前固定任务中不变化；固定任务的类别词汇/目标不变可自然产生常量，常量数量本身不是错误证据。真正需要补足的是候选相关、执行前可知的物理风险和局部关系。

### 已观察到的独立执行差异

- seed3302：价值选llm_007，分数0.894，换扰动后推物接触进度不足；随机选llm_006，分数0.117，最终通过。两条都是released_push，不能用禁用某种模式解决。
- seed3390：价值选llm_007，分数0.817，换扰动后推物失败；随机/Full8选其他候选通过。
- seed3372：价值选llm_003通过，随机/Full8选llm_002，放置支撑接触不足。
- seed3317：三方案选同一候选，名义通过、换扰动后双侧抓取接触不足。

以上是这次已观察试验的失败，不是某计划稳定失败率的估计。每条计划只采一个扰动标签，难以直接区分稳定成功和偶然成功；不能将单个高分失败直接解释为概率校准失效。

## 2. 优先级一：输入补齐，先保持现有小网络

在同一GNN上先比较以下特征增量，避免把表示、损失和结构一起改变：

1. 对象—目标、对象—对象、末端—对象的相对位姿、轴线夹角、推物长度、侧向偏移、抓取开口和物体尺寸关系。
2. 由执行前观测和候选计划计算的粗几何特征：路径/夹爪与障碍物间隙、抓取与放置支撑几何、接近方向、允许公差、必要几何条件的pass/unknown/rejected和裕量。不能把unknown当成pass。
3. 后续动作的预测场景必须使用前序动作的条件目标位姿；明确区分观测状态、条件预测与延迟求解。不要重新引入原先“旧供料姿态当障碍”的错误。
4. 使用类型化连续数值字段保留关键物理量；小类别表使用嵌入和未知类别标记。当前每类24桶哈希可能混叠，但尚未通过消融证明影响程度。

优先离线重建现有800训练/96验证的输入。初态机器人信息仅在能从原冻结观测可靠恢复时使用；无法恢复的维度保留缺失标记。特征计算应设计算预算，不能在编码器里偷偷完整调用物理孪生。

禁止把采集后的接触力、真实终态、实际成功阶段或失败原因作为执行前价值输入。这些信息只能当训练监督，或作为已经完成孪生后的独立复核模块输入。

## 3. 优先级二：增加同候选的扰动重复，而不是只增加不同候选

保持原计划、布局、控制器与标签规则。对训练/验证候选按预先固定的扰动分布增加重复，保存每次原始标签和参数；不重写原1000条，也不按成功与否决定是否保留。

- 先做一个固定随机选择的pilot：20个train布局×8候选×3个新扰动=480次，加原12个validation布局×8×3=288次，共768次新增执行。所有候选都执行；该规模只用于检查收益和标签稳定性，3次不够宣称单计划高可靠。
- 若有明显收益，扩到原100个train布局全部8候选，新增3个扰动，共2400次train执行，加288次validation执行。不能把768次pilot与后续扩展重复算或重复执行。
- 已有部署repeat=1数据只覆盖被三方案选中的测试候选，具有选择偏差，不能直接拼入训练。
- 第一阶段针对当前评估中的摩擦和执行器增益分布；感知位姿噪声等作为另一个预先声明的任务扩展，不混同于原V32测试。
- 同一布局的所有候选与所有重复必须归属同一split。训练/验证扰动与最终测试扰动种子独立。

重复采样标签用于估计鲁棒成功概率；按重复数构造二项似然或等价计数BCE，保留样本数和不确定性。每条只有少数重复时可以用收缩估计，不能把3/3当成确定100%成功。

这种“几何和扰动下的抓取可靠性”学习方向可参考 [Dex-Net 2.0](https://arxiv.org/abs/1703.09312)，但其任务和数据规模与这里不同，不能照搬其成功率。

## 4. 模型输出与结构建议

第一步维持64维、小参数规模，增加输出和正确监督。先逐项消融，再决定是否需要更复杂的结构。

| 输出 | 训练数据/监督 | 用途 |
|---|---|---|
| 名义验证通过概率 p_nominal | 原1000条中的train记录 | 预测当前验证配置能否通过 |
| 扰动下成功概率 p_robust | train候选重复执行 | 倾向选择稳定方案 |
| 验证成本 c_twin | 实际仿真步数、求解计数、受控环境计时 | 预测昂贵失败，辅助排序 |
| 不确定性 u | 3个预先固定初始化的独立模型分歧，并在validation验证 | 决定是否增加验证预算，不能当作保证 |

可加动作/阶段通过或失败风险的辅助头，重用现有trace监督；只监督实际到达的阶段。上游失败后未执行阶段应mask，不能把整段后续False都当成独立失败。模型不能在推理时读真实trace。

若补输入、标签和多头后仍欠拟合，再比较“对象关系编码 + 原子技能图编码 + 按动作顺序汇聚”的小型层次结构，例如关系图层后加入轻量GRU/注意力池化。当前两轮消息传递可能不足以传递长计划依赖，但尚无消融支持必须换Transformer。大模型和更多层暂列低优先级。

概率头优先使用恰当的概率损失；排序头可单独使用同布局成对或列表损失，避免仅为名次优化而牺牲概率解释。多个初始化平均及分歧估计可参考 [Deep Ensembles](https://arxiv.org/abs/1612.01474)；模型分歧不足以涵盖所有物理随机性。

## 5. 筛选策略要优化成功率与耗时的共同目标

采用“最小化期望流程耗时，满足预先规定的整体成功率约束”的选择目标；阈值和权重只通过训练内交叉验证和validation选择，不能在当前13个test上调。

### 成本排序

若仅考虑顺序验证直到首个通过，且候选成功事件独立、验证成本不随顺序改变，则比较a→b和b→a的期望成本可得到按 p_nominal/c_twin 排序的规则。实际候选共享布局、失败相关且预算有限，这个规则只能作为成本基线。生产选择还需p_robust约束；不能为了快速失败而提升低成功率计划。

成本标签不要直接把8并发采集的墙钟当稳定算力成本。先使用仿真步数/求解计数和受控计时校准，并报告误差。

### 分级预算和多样性

固定Top4可改为首批Top1或Top2，再按置信度扩到4/8；置信度低或候选同质时加入不同抓取/运输/路径方式的备选。相关性使 1−∏(1−p_i) 不能直接作为已校准的候选池成功概率。高置信度也不能未经验证直接跳过孪生。

### 首次通过后的鲁棒性复核

对首次通过者，可使用孪生执行时已经产生的接触、支撑和进度裕量，训练独立的后验风险模块，判断是否值得追加一个预先定义的新扰动验证或换备选。这些后验特征属于“验证之后”的模块，不能混入执行前评分或预先候选排序。

额外复核增加时间，不能默认每个候选都多跑。须在相同总时间/验证预算下与采用相同复核规则的随机基线比较，并把所有新调用计入整体耗时。没有重复鲁棒标签前，不能声称这种复核必然有效。

## 6. 下一轮最小实验矩阵

1. A：冻结V32，作为历史基线。
2. B：输入补齐，网络/损失/采集标签不变，检查表示收益。
3. C：B加鲁棒重复数据及鲁棒输出，检查最终执行收益。
4. D：C加成本输出与分级预算，检查同成功率下时间收益。
5. E：仅在前面验证支持时加入集成和后验风险复核。

先在100个原train布局内按布局做交叉验证，用原12布局validation完成选择。原13个test已被用于诊断，维持历史基准，不能反复作为“未见测试”。最终另冻结一批新布局，例如先规划50—100布局和独立部署扰动；其规模是否足够应根据所需置信区间/最小效应决定，不保证足以分辨几个百分点。

所有方案使用相同冻结候选池、相同验证和部署扰动集合及总预算。随机基线报告多个预先固定随机顺序的均值和区间，不能仅靠一次排列。补充“原顺序依次验证，首个成功即停”的基线；现Full8是全部验证的较昂贵基线，不能单靠对它省时就宣称模型收益充分。

指标优先：布局整体成功率、失败保留在分母的总体墙钟、成功率—成本曲线、候选校准/Hit@1/2/4、验证次数、独立扰动失败率、模型不确定性与错误的关系。不能通过早失败、拒绝困难布局或只统计成功布局制造加速。

建议顺序：补执行前物理特征 → 小规模重复扰动pilot → 鲁棒成功监督 → 成本与分级预算 → 再考虑扩大网络。当前证据最支持前三项，具体收益必须通过上述消融和新冻结测试证明。
