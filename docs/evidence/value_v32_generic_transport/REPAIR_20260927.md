## 续采与恢复方法

`scripts.resume_dataset_v32` 校验仅候选几何文件发生变化、保持所有原定布局和划分、逐条核查完成文件后跳过已经完整的布局。对执行前失败的同一 seed 归档后重试；对部分执行且有冻结请求的布局，只按冻结候选补齐缺失执行。已经写出的无效样本会暂停并要求排查，不能偷偷重跑变成有效负例。文件锁避免双重续采。

远端命令（工作目录必须是上列远端根目录）：

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 TWINGRAPH_EXTERNAL_PLANNER=1 MUJOCO_GL=egl /home/jia/twingraph-v8-mj237/bin/python -m scripts.resume_dataset_v32 --out results/dataset_1000 --original-runtime results/dataset_1000/revisions/original/runtime.json --workers 8
```

本地转发：

```powershell
python -u -m scripts.relay_planner_v32 --resume-existing
```
