# V30：滑块入口释放、闭合推进、把手安装即终止

> 此页是已废止的 V30 实验记录。V30 在释放后重新夹住滑块，实际执行的是夹持搬运，不符合“闭合空夹爪从后往前推”的动作要求。下方 0/16 结果仅适用于 V30，不能用作修正后流程的统计。修正实现和新一轮实验见 V31 记录。

## 流程

- 滑块先从上方放到导轨入口受支承的位置，松开夹爪；随后在原位重新闭合夹爪，沿导轨推到目标位，并释放。入口滑块中心世界坐标约为 x=−0.030 m，目标 x=0.105 m；目标位于可用行程 x=0.035～0.135 m 的 70% 处。
- 安装把手前重新获取滑块位姿，本次使用 MuJoCo 状态观测，并与静态 CAD 的手柄柱配合关系计算把手目标。
- 把手安装、释放和最终装配检查后结束；不执行抓取把手的往返滑动测试。

## 一组随机布局的结果

- 随机布局：L0 broad，seed=2788；状态观测位置与偏航噪声均为 0，物理扰动域为 regression。布局生成无结果筛选。
- 冻结 16 条互不重复的完整候选；最终有效 16/16，正样本 **0/16**。
- `grounded_009` 首次运行触及 600 s 预算；同一观测、相同候选计划哈希以 1200 s 复跑，得到有效负例。
- 失败阶段：滑块 7、端挡 1、插销 1、把手 7。到达把手阶段的 7 条候选均未通过最终把手安装。
- 观测 SHA-256：`54ed5b833f4206854da3ae8beb354a125ca58cf49460d63629a8505644ee3e6c`；运行时 SHA-256：`fad10f269761a6dcb2a2dab508788d85ea2876e81f4fa93d44145da5f39dbd10`。
