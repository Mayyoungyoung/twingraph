# V23 无擦拭完整滑台装配：底座孔严格验收

## 固定任务与标签

本阶段从放置滑块开始，依次装配挡板、左右插销和把手，执行双向功能行程，最后释放并检查保持状态。擦拭清洁不在任务内。决策输入由 MuJoCo 状态位姿生成；首次采集为零观测噪声，补充条件为位置标准差 0.3 mm、偏航标准差 0.3°。每个布局从同一版生成器生成 48 个提案，冻结其中前 8 个不同的完整合理候选后再执行。执行与验收代码在采集期间按运行时指纹固定。

成功必须满足完整装配、功能行程、挡板稳定支撑、最终座合、释放与回撤，以及**左右插销均同时进入挡板孔和底座孔**。每根插销在释放后和功能行程后都通过两个接收件的独立几何／接触验收。V22 仅挡板孔验收的成功标签不能混入 V23。挡板允许稳定支撑放置，无须满足旧版过严的定位桥接诊断；诊断值仍保留。

## 原定六布局首批自然覆盖

布局和预算见 [collection_manifest.json](collection_manifest.json)。其中 2050、2060、2061 来自原工作范围；3000、3001、3002 按同一规则从 2050 的成功供料配置邻域抽样，无按执行结果调坐标。2050 及其邻域共享 `neighborhood_parent_2050` 划分组。

| 布局 | 来源 | 首批成功／8 | 池类型 |
| --- | --- | ---: | --- |
| 2050 | 原工作范围 | 0 | 全负 |
| 2060 | 原工作范围 | 0 | 全负 |
| 2061 | 原工作范围 | 0 | 全负 |
| 3000 | 邻域 | 2 | 混合 |
| 3001 | 邻域 | 0 | 全负 |

总计 48 条有效执行，3 正、45 负；6 个布局中 2 个混合池。45 条负例的首要类别为控制／接触失败 19、路径检查拒绝 14、抓法求解预算耗尽 9、功能验收失败 3。8 条候选到达功能行程，3 条完成。求解预算耗尽和路径拒绝表示本轮未完成，不宣称物理上绝对不可行。

逐条可移植样本在 [first_pass_samples.jsonl](first_pass_samples.jsonl)，包含决策时观测、完整候选 PlanIR、实际执行标签、失败原子调用、阶段标签、双层孔与最终功能谓词、观测随机状态和耗时。[first_pass_audit.json](first_pass_audit.json) 记录冻结内容、标签及三条正例双层插销保持验收的逐条审计。忽略目录 `results/v23_*` 中保留原始请求、逐候选结果、原子轨迹、阶段程序及软件异常／中断记录；导出的 JSONL 对 3 条正例的旧版辅助诊断中的无穷大哨兵值改为 `null`，并标记原字段路径，原始记录未变。

采集期间的三次内存压力中断与一次完成后终端汇总打印异常列于 [collection_anomalies.json](collection_anomalies.json)。中断发生在首条候选完成前，未产生物理负例；重试保留相同冻结请求。3002 的最后打印异常发生在全部逐条结果及汇总写入后，8 条标签均通过审计。

## 配对复验与其他采集

邻域 3000 的首个成功候选 `grounded_043` 在相同初态、相同随机状态下再次成功，换预先声明的物理扰动后失败。代表性失败候选 `grounded_023` 的两次复验均被路径检查拒绝；`grounded_024` 同条件为功能验收失败，换扰动后为控制／接触失败。6 条重复执行记录和审计样本见 [paired_replay_samples.jsonl](paired_replay_samples.jsonl)。这些结果仅描述少量重复的实际标签，不是精确成功概率，也不进入首批自然覆盖率。

邻域 3002 的成功候选 `grounded_033` 在相同条件及改变物理扰动后均重放成功。失败候选 `grounded_044` 两次均被路径检查拒绝；`grounded_030` 同条件为控制／接触失败，换扰动后为功能验收失败。6 条逐条记录见 [paired_replay_3002_samples.jsonl](paired_replay_3002_samples.jsonl)。

额外零噪声邻域布局预先记于 [development_addendum.json](development_addendum.json)，0.3 mm／0.3° 补充条件记于 [supplemental_manifest.json](supplemental_manifest.json)。两者均与原定六布局首批统计分开。

0.3 mm／0.3° 补充条件的邻域 3000 与 3002 均为 0/8；16 条逐条记录在 [supplemental_noise_samples.jsonl](supplemental_noise_samples.jsonl)。其中 12 条在挡板放置后的共线通道必要检查被拒，4 条在路径检查被拒；这是正常执行中的前置条件失败，不是软件异常，也不证明这些方案物理上绝对不可行。这档观测噪声对当前装配链有明显影响；该结果只覆盖这两个布局及固定预算。

额外零噪声开发补采的邻域 3003 为 1/8、3004 为 0/8；16 条逐条记录在 [development_samples.jsonl](development_samples.jsonl)。3003 是新增混合池，但作为后续开发采集单独报告。原定六布局与开发补采合计 64 条零噪声执行，4 正、60 负；这个合计不能替代原定六布局的自然覆盖统计。

上述 10 个采集池的逐候选完整性与严格双层孔正例检查汇总见 [all_pools_audit.json](all_pools_audit.json)：80/80 条有效，4 条正例。复验另有 18 条有效执行，不进入这个分母。

3003 的 `grounded_038` 在同条件下重放成功，改变物理扰动后控制／接触失败；`grounded_018` 两次均为控制／接触失败，`grounded_017` 两次均被路径检查拒绝。6 条复验样本见 [paired_replay_3003_samples.jsonl](paired_replay_3003_samples.jsonl)。三个混合池共保存 18 次配对复验，均与首轮候选标签分开。
