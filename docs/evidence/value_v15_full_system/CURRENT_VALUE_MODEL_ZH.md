# V15 当前价值模块：统一原子技能图输入

## 结论先行

V15 不再把滑台任务预先拆成 `cleaning/carriage/end_stop/pin_left/...` 八个固定槽位。价值模块读取的是规划器已经编译并通过接口校验的**完整可执行原子技能图**。只要新任务继续使用注册的原子技能、端口、状态读写和观测契约，就不需要人为为该任务另写一套价值输入；需要变化的是任务数据和数字孪生标签，而不是输入字段表。

模型输出是“该完整计划在当前观测和所训练孪生分布下完成全部功能谓词的估计概率”，只用于排序。它不是碰撞证明、成功保证或真实机器人安全认证。

## 从旧输入到 V15 输入

V12–V14 的图模型虽已读取技能图，但编码器仍硬编码八个装配阶段，并为特定部件建立固定交互槽。这会导致换任务时必须修改 `STAGES`、部件循环和特征位置。

V15 的输入契约为 `twingraph.atomic_graph_value.v15.r2`：

- 节点就是完整 PlanIR 中实际执行的原子技能调用，节点数动态变化；批处理时只补零到该批最大节点数，不把任务裁成八个阶段。
- 当前安全上限为 512 个节点；超过上限直接报错，不静默截断。
- 边统一使用原子图已有的七类关系：`execution`、`data`、`object_state`、`holding`、`scene`、`robot`、`observations`。
- 每个节点 303 维，其中 264 维是 11 组、每组 24 桶的稳定 SHA-256 特征哈希，39 维是连续值和缺失掩码。

11 组哈希分别表示：技能、实际实现、技能族、对象角色、前置/效果/义务、数值端口值、已知数值端口、延迟求解数值端口、类别端口、状态读写、任务目标。向量和路径端口逐分量哈希，并额外记录长度，绝不压成均值。连续尾部表示调用位置、执行边界、节点类型、端口已知/延迟/未知比例、状态读写数、图入出度、被操作对象的观测位置/残差/质量/偏航、机器人关节和末端观测、通用几何条件状态与裕量、图规模。

部件名称可以作为“对象角色取值”被哈希，但编码器没有 `carriage` 或 `pin_left` 的专用列。新名称自然落入同一哈希空间。未注册技能、非法关系、非有限控制数值、图与 PlanIR/接口不一致都会被拒绝。

明确不进入输入的内容包括：候选名称或编号、布局 seed、孪生成功标签、错误字符串、执行耗时、最终位置和任何 rollout 后统计。相关回归测试验证了给图外层加入这些字段不会改变编码。

## 网络结构

当前结构由 `AtomicValueNetV15` 实现：

1. 303 维节点输入经训练集均值/标准差归一化，标准差下限 0.1，值裁到 `[-8, 8]`。
2. `Linear(303,64) + GELU + LayerNorm` 得到节点表示。
3. 两层关系消息传递；七类边均计算正向和反向消息，每层再用残差更新节点。
4. 对动态节点集合同时做注意力池化、掩码均值池化和掩码最大池化。
5. 三种池化结果拼接后经 `Linear(192,64) + GELU + Dropout(0.1) + Linear(64,1)` 得到完整计划 logit，推理时取 sigmoid。

宽度 64、两层消息传递的模型共有 165,570 个可训练参数。图校验和编码不依赖 PyTorch；训练/推理部分才加载 PyTorch。

## 标签和训练

正标签只来自一次新鲜数字孪生 rollout 中全部六个功能谓词同时通过：清洁、装配、双向行程、挡块捕获、最终就位、释放退回。前缀成功、资源超时、无效运行和软件接口错误均不能当成负标签。

划分单位是布局，不是候选行。损失为：

- 每布局平衡的完整任务 BCE；混合布局中正负候选各占一半权重；
- 同布局成功候选相对失败候选的成对排序损失，权重 0.5；
- 不使用测试布局选 epoch、初始化或 K。

选择顺序预先固定为：验证 Hit@4 最大、归一化首次成功调用数最小、同布局成对准确率最大、Brier 最小、epoch 最早。

## 已完成的历史完整任务预训练

第一阶段使用审计过的 V12 原生完整任务档案：训练布局 1610–1613、验证布局 1630–1631，共 6 个布局、288 个完整计划标签，每布局 48 条。该档案与当前运行时严格区分，只用于预训练。

三个初始化中选中 1502、epoch 2，checkpoint SHA-256 为 `9720138360c20ffa6b07ea2af0c3d2062d5b54bc482f22675e135dbf1a89020b`。历史验证集只有两个布局且仅一个候选池可解，因此只能作小样本开发证据：

- Full-N 覆盖：1/2；
- V15 Hit@4：1/2；精确均匀随机 Hit@4 期望：0.212；原始顺序 Hit@4：0/2；
- V15 平均验证调用数：2.5；随机期望：3.651；
- Brier：0.1862；同布局成对准确率：0.4603。

这些数不能证明泛化收益。当前运行时与历史运行时严格分开：当前严格运行时的布局 1950、1951 均为 0/24，1950 的五条池扩展也全部失败；在隔离的审计物理基线上，Codex→价值 Top‑4→完整孪生闭环两轮共八次新鲜精验亦全部失败。详细统计和 NO‑GO 判断见 `REPORT_ZH.md` 与 `RESULTS.json`，不能与历史小样本排序结果混算。
