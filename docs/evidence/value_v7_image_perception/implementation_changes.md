# 本轮实现记录

- 建立分支 `research/value-v7-image-perception`，基于已有 v7 工作树，不回退到旧提交。
- 新增纯函数 RGB-D 几何检测器和相机标定/观测哈希；检测分辨率 640×480，价值输入保留 80×80。
- `stage_v7` 默认使用 `rgbd_geometry`，在关键执行边界重新观测，工具放置和清洁轨迹
  使用视觉工具位置，挡块孔位和安装把手使用当前图像估计。
- 新增 `pin_geometry.py`，把销插入改为孔道几何、深度和松爪保持验收；不修改其它零件
  的严格位姿验收。
- pin v7 候选的夹持力改为 5.0/6.5/8.0 N 三档，作为实际执行参数；原因是上一条
  轨迹在孔口约 8 N 接触时以 2.8–3.2 N 夹持力丢失，不能靠放宽标签解决。
- 新增纯检测、空白/无效深度、移动响应和插入阶段单元测试；当前相关回归测试为 14/14 通过。
- 新增 `scripts/run_v7_full_task_smoke.py` 和 `scripts/evaluate_v7_rgbd_perception.py`，
  分别用于可复现的真实开发轨迹/视频和留出感知审计。

本轮没有启动 9600 次正式数据采集；必须先完成局部视觉驱动完整任务链并冻结协议。
