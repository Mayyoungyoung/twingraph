# TwinGraph v7 价值模块报告（开发阶段）

## 当前结论

本报告对应新分支的开发实现，不是正式 128/32/64 场景结果。清洁阶段已经在 MuJoCo 中真实夹取擦拭工具、建立 pad—导轨接触、产生切向运动，并将 32 个可见污迹站点从环境状态中清除；悬空/静止/侧面接触不会直接改变污迹。25 次开发重放中清洁通过 24 次、装配阶段通过 2 次；严格的 pin 放爪验收仍暴露约 5 mm/7° 倾倒，当前完整任务成功数仍为 0，不能声称完整任务已经完成。

## 对用户问题的直接回答

1. 擦拭已真正执行并进入 v7 阶段标签；旧 v6 没有。滑动控制、把手执行期重新观测和双向验收已接入代码，但在 pin 稳定性修正完成前尚未形成成功完整任务标签。
2. 仍保留模拟传感器代理、简化污迹材料模型和仿真真值独立验收器；不能称为真实 RGB-D 检测或真实材料清洁。
3. 候选现在会改变合法顺序、抓取 yaw/高度/力/速度、路径 clearance、擦拭方向/持续时间和最终行程测试；v7 语义去重后再进入池。
4. 当前开发失败集中在 L1 接近误差，以及 L0/L1 pin 插入后脱离夹爪的支撑/倾倒；这是实现和几何稳定性问题，仍在开发集定位。
5. 四视角正式准确率、Brier、排序和速度尚未运行，不能提前宣称哪个最好。
6. 图像收益尚无 v7 正式证据；none 保留共同结构化感知成本，图像仅是额外输入。
7. 价值 Top-4 与随机/启发式尚未执行，不能宣称优于简单方法。
8. Full-12 与 Top-4 的节时/成功率尚未执行。
9. 已完成：代码审计、观测接口、清洁状态、双向行程验收、v7 候选与采集管线、开发真实失败轨迹和失败视频准备。未完成：正式训练、held-out 测试、系统对照、完整成功视频、12 候选及 Top-4 视频全集。
10. 当前最值得扩大的是任务几何/接触稳定性和观测接口验证，其次才是数据规模和模型方法。

正式结果会在所有数据和模型完成后追加；pending 表格不代表零分。
