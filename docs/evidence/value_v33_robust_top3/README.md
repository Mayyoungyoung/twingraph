# V33 鲁棒价值 Top3 实验

## 结果

实验于 2026-09-30 完成。V33 在 1000 条候选数据上训练，并对训练/验证布局补采 2688 次扰动执行；最终冻结模型后，在 4000—4049 共 50 个全新布局上运行 3 组配对验证/独立部署流程，每个方案共 150 次流程。全部结果经过哈希、标签一致性、模型冻结和测试集隔离审计。

| 方案 | 最终成功 | 成功率 | 平均验证次数 | 平均完整流程秒 |
|---|---:|---:|---:|---:|
| value_top3 | 131/150 | 87.3% | 1.400 | 811.16 |
| random_top3 | 71/150 | 47.3% | 2.333 | 726.14 |
| full8 | 129/150 | 86.0% | 8.000 | 2304.98 |

价值 Top3 相对随机 Top3 的配对成功率差为 +40.0 个百分点（bootstrap 95% 区间 +30.7～+50.0），相对 Full8 为 +1.3 个百分点（−1.3～+4.7）。相对 Full8，完整流程平均节省 1493.81 秒（−1616.62～−1372.13）。随机方案的流程均时较低，部分原因是它更常在验证阶段找不到通过候选而不进入独立部署；本轮结论因此只把价值方案描述为接近 Full8 成功率并显著减少验证成本。

## 代码和模型接口

V33 的训练、特征编码、冻结测试、流程评估和最终审计分别由以下脚本实现：

- `scripts/value_features_v33.py`：把执行前原子技能图、候选几何/控制参数和条件相对位置编码为每节点 371 维输入。
- `scripts/train_value_v33.py`：三头输出（名义成功、扰动成功、验证成本），按布局分组训练，使用二元损失、同布局排序损失和成本回归；只用训练/验证布局选择初始化、epoch、温度和排序权重。
- `scripts/freeze_test_value_v33.py`：冻结 50 个测试布局、候选池和模型哈希。
- `scripts/evaluate_workflow_v33.py`：配对执行 value Top3、random Top3、Full8。
- `scripts/finalize_value_v33.py`：复核每条结果、标签和哈希并生成最终报告。

冻结选择为 `enhanced_robust_17.pt`，输入维度 371、隐藏宽度 64、两层关系消息传递，约 170k 个可训练参数。仓库保存冻结配置和 checkpoint SHA256；原始权重、逐步轨迹及约 10GB 的运行目录保留在实验机 `901` 的 `results/` 下，未纳入 Git。

## 证据文件

- `REPORT_ZH.md`：远端生成的完整中文总结。
- `comparison.json`：50 个布局、450 个流程的逐布局机器可读结果。
- `candidate_test_metrics.json`：Full8 的 1200 次候选验证指标。
- `training_report.json`：训练/验证划分、消融与选择记录。
- `selection_frozen.json`：最终模型、温度、排序预算和哈希。
- `workflow_audit.json`：测试集隔离、重复标签一致性、流程和部署计数审计。

全部流程为数字孪生仿真；不包含新一轮 LLM 计划生成，也不代表实体机器人成功率。
