# 价值模块 v6：鲁棒监督与视觉消融

v6 保留 v5 的完整可执行技能程序和最终物理成败监督，但把监督目标从一次名义执行改为三次成对扰动下的经验成功率。每个场景的所有候选共享同一组扰动，避免某个候选仅因抽到更容易的摩擦或检测噪声而获得优势。扰动覆盖检测位置噪声、摩擦、执行器增益、零件质量和阻尼；初始供料位姿、光照、颜色与相机外参也按场景随机化。

## 图像是否需要

PIGINet 使用图像的主要动机是补充对象几何、遮挡和未知物体外观，并在宽厨房中组合侧视与目标区域顶视。本任务的零件类别和 CAD 几何固定，而且结构化观测已经包含检测得到的位姿，因此图像很可能与数值状态冗余；是否保留不能只靠直觉决定。

正式实验训练四个预先声明的输入版本：无图像、全局斜俯视 RGB-D、顶视 RGB-D、两视角 RGB-D。视角和模型只按验证集配置级 Brier 分数选择，测试集不参与选择。只有视觉版本在验证集上胜出时，部署模型才要求图像。

腕部近景没有作为当前价值决策的输入。价值评分发生在候选执行之前，而腕部近景需要机器人先移动到观察位姿；在没有显式检测动作与对应耗时的情况下使用这种图像会越过真实决策边界。若后续系统把主动观察作为候选计划的一部分，应将观察动作、所得图像和额外时间一起建模。

## 视角

- `task_view`：固定全局斜俯视，覆盖机器人、五个供料零件和装配巢，保留高度与遮挡线索。
- `top_view`：固定顶视，覆盖供料区和装配巢，突出 XY 布局、孔位与横向余量。

每个视角保存 80×80 RGB 和毫米深度。训练只做亮度、对比度、轻微 RGB/深度噪声，不做左右翻转，因为左右销和装配顺序具有物理语义。

## 指标与系统对照

候选的鲁棒二值标签定义为三次完整执行中至少两次成功，同时保留三次成功率用于 Brier 分数。正式数据包含 96 个独立场景、1,152 条候选程序和 3,456 次完整物理执行。独立测试报告准确率、平衡准确率、ROC-AUC、Top-4 命中率和候选成功率富集。完整系统在 12 个未见配置上实际运行 Top-4 与全量 12 条数字孪生筛选，两者都从新建的独立目标仿真执行选中计划，报告决策耗时、端到端耗时和目标成功率。
