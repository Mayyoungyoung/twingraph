# Panda asset provenance

The robot/gripper kinematics and collision meshes derive from robosuite (MIT); the visual OBJ meshes derive from MuJoCo Menagerie franka_emika_panda (Apache-2.0), as documented in panda.xml. Upstream licenses are included alongside this file.

The existing panda.xml contains local modifications to actuators, placement, visuals and contact geometry. No license is imposed on unrelated project code by these asset notices.
